# Game SEO Plan

این برنامه برای گرفتن ورودی ارگانیک روی اسم بازی‌ها و کوئری‌های کامیونیتی/هم‌تیمی طراحی شده است.

## اولویت URLها

- `/games/` صفحه مادر
- `/games/<id>/` لندینگ اصلی هر بازی
- بعداً فقط برای بازی‌های پرتقاضا:
  - FAQ همان بازی
  - راهنمای شروع
  - صفحه هم‌تیمی/LFG ایندکس‌پذیر فقط اگر محتوای کافی داشت

## کلاستر کوئری برای هر بازی

- `[اسم بازی]`
- `[اسم فارسی بازی]`
- `کامیونیتی [اسم بازی]`
- `هم تیمی [اسم بازی]`
- `LFG [اسم بازی]`
- `کلاب [اسم بازی]`
- `ریویو [اسم بازی]`
- `بازی [اسم بازی] در گیم بیت`

## اجزای لازم در هر صفحه بازی

- H1 با نام فارسی اصلی
- نمایش نام انگلیسی زیر H1
- توضیح فارسی منحصربه‌فرد
- ژانر، پلتفرم، سال انتشار
- ریویوها و امتیاز کاربران
- لینک داخلی به بازی‌های مشابه
- باکس فعالیت کامیونیتی: پست، LFG، کلاب، کانال
- اسکیما `VideoGame` و در صورت وجود سوالات پرتکرار، `FAQPage`

## اولویت اجرایی

- فاز 1: تکمیل نام فارسی اصلی و توضیح فارسی برای بازی‌های موجود
- فاز 2: تمرکز روی 20 بازی بالا
- فاز 3: ساخت لینک‌سازی داخلی از پست‌ها، هشتگ‌ها، LFG و پروفایل‌ها به صفحه بازی
- فاز 4: تولید FAQ و راهنما برای بازی‌هایی که Impression می‌گیرند
